# Content

Published, ship-ready content pieces.

## Structure

| Folder | Content type |
|--------|-------------|
| [Blog Posts](Blog%20Posts/) | Narrative, educational blog content |
| [Comparison Articles](Comparison%20Articles/) | Head-to-head product comparisons |
| [How-to Guides](How-to%20Guides/) | Step-by-step instructional content |
| [Listicles](Listicles/) | Numbered or bulleted list format |
| [Glossary](Glossary/) | Short definitional entries |
| [Case Studies](Case%20Studies/) | Customer or use-case success stories |
| [Use Case Pages](Use%20Case%20Pages/) | Audience-targeted job-to-be-done pages |

Each type folder is created the first time a piece of that type is published.
